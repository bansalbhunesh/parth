# Impeccable — Project Design Context

## Design Context

### Users
Two audiences, both time-poor and skeptical:
1. **Hackathon judges** (ET AI Hackathon 2026, PS4 — enterprise/technical
   panel): first contact is a pasted link or the GitHub repo; the decisive
   window is the 90-second Judge Mode flow, often on a projector or a phone.
   Their job: verify the claims fast and find the holes.
2. **EPC / commissioning practitioners** (CxAs, MEP leads, owner's engineers):
   evaluate whether the tool matches a workflow they live daily. They read
   dense tables for a living and distrust marketing gloss.

### Brand Personality
**Evidence-first · precise · honest.** The product's motto is "evidence before
confidence" — every number ships with its limitation, a claims register bans
the project's own hype, and the UI must *feel* like a calibrated engineering
instrument, not a pitch deck. Nothing should look decorative for decoration's
sake; anything that looks like hype erodes the core differentiator.

### Aesthetic Direction
Dark engineering-instrument panel: near-black blue-tinted surfaces (#0a0d11
family), a single cyan signal accent (#00d4ff), status colors used
semantically (green=pass, amber=caution, red=fault), JetBrains Mono for
numbers/identifiers + Inter for prose. Dark theme is *derived*, not default:
the reference environment is a NOC/commissioning-war-room aesthetic the target
users inhabit. Anti-references: SaaS marketing gradients, glassmorphism,
mascot playfulness.

### Design Principles
1. **Numbers are the interface** — metrics render in mono, always adjacent to
   their limitation or provenance chip; no number without its caveat.
2. **Semantic color only** — cyan for identity/interactive, green/amber/red
   strictly for status; never decorative neon.
3. **Degrade honestly** — offline/fallback/cold states are first-class UI
   (provenance chips, "rule floor" badges), never faked or hidden.
4. **Density with rhythm** — practitioners want data-dense tables; hierarchy
   comes from spacing rhythm and type scale, not decoration.
5. **Ship-freeze discipline** — visual changes near the submission deadline
   must be low-risk and reversible; polish never jeopardizes the frozen
   claims surfaces.
