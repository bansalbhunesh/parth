# Vendor Submittal — Cooling — Chillers / CRAH / Liquid Loop (COOL)
_Project: Project Meghdoot · Submittal rev B_

## Vendor Notes

Vendor: York YVWA 1500 TR water-cooled screw chillers.
Configuration: 4 x 1500 TR chillers in N+1 arrangement.
The chiller plant is proposed as 3 duty + 1 standby (N+1) which the vendor notes provides 33% excess capacity above the N requirement. The P&ID shows a common header with isolation valves per chiller.
Chilled water design delta-T: 7 deg C (12/5 deg C supply/return). The vendor sizing is based on the standard catalogue selection for this chiller frame and notes higher delta-T requires custom coils.

## Provided values

- **COOL-LOOP** — redundancy: **N+1 topology** (vendor datasheet)
- **CRAH** — supply air temp c: **24 C** (vendor datasheet)
- **CHILLER** — capacity tr: **1500 TR** (vendor datasheet)
- **COOL-LOOP** — delta t c: **7 C** (vendor datasheet)
