# EN 50600 — Information Technology: Data Centre Facilities (paraphrased)

European standard for data centre design and operation.

## Availability Classes
- Class 1: Basic site infrastructure
- Class 2: Redundant capacity components
- Class 3: Concurrently maintainable (N+1 paths)
- Class 4: Fault tolerant (2N paths)

## EN 50600-2-2: Power distribution
- UPS autonomy >= 10 min for Class 3+
- N+1 redundancy minimum for Class 3

## EN 50600-2-3: Environmental control
- References ASHRAE TC 9.9 for temperature envelopes
- Energy efficiency per EU Code of Conduct
