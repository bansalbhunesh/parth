# Vendor Submittal — Fire Pump Diesel Driver
_Project Meridian DC-3 · Submittal SUB-MERIDIAN-3 · Rev A_

The proposed fire pump driver is a Clarke Fire Protection Products
JU4H-UFADJ2, built on a John Deere 4045HF280-series base engine.

## 1. Diesel Fire Pump Driver — Clarke JU4H-UFADJ2

- **Power rating.** 99 BHP / 74 kW, constant-speed, certified at 2,100 or
  2,350 RPM depending on pump match. 74 kW falls within the 56–75 kW
  design-basis power class.
- **Emissions certification.** EPA Family Name **CJDXL04.5141**, EPA
  Certificate Number **CJDXL04.5141-027**, 2012 engine model year — listed
  in Clarke's own published Tier 3 Certified Engines summary for the
  2012 model year (clarkefire.com, "Tier 3 Certified Engines for Clarke
  Fire Protection Products, Inc.", 2012 Engine Model Year). Under 40 CFR
  60 Subpart IIII Table 3, engines in this power class (56 ≤ kW < 75) must
  be certified starting model year 2011; a 2012-model-year certified
  engine is certified against the 2011-and-later Table 4 row for its
  class — the same row the design basis quotes (NMHC+NOx ≤ 4.7 g/kW-hr,
  CO ≤ 5.0 g/kW-hr, PM ≤ 0.40 g/kW-hr).
- **What is and isn't verified here.** The EPA Family/Certificate Number
  and power/speed/model-year figures are Clarke's own published data,
  cross-checked against the primary regulatory text in
  `../primary_sources/40_CFR_60_Subpart_IIII.md`. The specific measured
  g/kW-hr test result for this exact engine family was **not** located in
  this pass (Clarke's public emissions-summary PDF lists certificate
  identifiers, not raw test numbers, for this model) — compliance is
  inferred from the certificate's existence for the stated tier/model
  year, which is what an EPA certificate legally attests to, not from an
  independently reproduced test value.
