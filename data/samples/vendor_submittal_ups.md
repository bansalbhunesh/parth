# TECHNICAL SUBMITTAL — PowerGuard ePX-1000 Uninterruptible Power System
### Submitted by: Apex Critical Power Pvt. Ltd. · Submittal No. APX-EL-0241 · For Approval

Apex Critical Power is pleased to submit the **PowerGuard ePX-1000** modular UPS
platform for the Helios Data Centre critical power application. The ePX-1000 is a
field-proven, transformer-free double-conversion system trusted by leading
hyperscale operators worldwide.

---

#### 1. System Overview

The proposed solution comprises modular UPS units arranged in an **N+1 redundant**
configuration on each power bus, delivering excellent availability while
optimising capital cost and footprint for the client. Each frame accepts hot-
swappable power modules for concurrent maintenance.

#### 2. Guaranteed Technical Particulars

| Item | Particular | Offered Value |
|------|-----------|---------------|
| 2.1 | Topology | Double conversion, VFI-SS-111 |
| 2.2 | Module rated active power | 1000 kW |
| 2.3 | System redundancy (per bus) | **N+1** |
| 2.4 | Battery autonomy at full rated load | **8 minutes** (VRLA, beginning of life @ 25 °C) |
| 2.5 | Online efficiency at 100% load | **96.5%** |
| 2.6 | Input current THD | < 3% |
| 2.7 | Audible noise @ 1 m | 71 dB(A) |

#### 3. Battery System

The offered battery is a high-rate VRLA string optimised for a compact footprint.
Quoted autonomy of 8 minutes is stated at beginning of life at 25 °C. An extended-
runtime option is available on request should the project require additional
backup time.

#### 4. Compliance Statement

Apex Critical Power confirms the ePX-1000 meets or exceeds all applicable
performance requirements for double-conversion efficiency, harmonic distortion,
and acoustic performance, and is offered as fully compliant with the project
specification.
