# Performance evidence

This directory contains dated, non-overwriting summaries of performance runs.
Each artifact records the source revision, profile, tool/runtime metadata,
individual samples, medians, source-report hashes, and limitations.

Local lab artifacts are directional diagnostics, not production Core Web
Vitals or release proof. The release gate requires repeatable Linux/production
Lighthouse results and field INP p75 evidence.

## 2026-07-16 Linux CI diagnostic

Generated by [`.github/workflows/perf.yml`](../../../.github/workflows/perf.yml) on
`ubuntu-latest` against the standalone production bundle (`scripts/start-standalone.mjs`
on `127.0.0.1:3100`), Lighthouse mobile via `@lhci/cli`, five runs, median-of-five.
Source revision `336619f`. Run:
<https://github.com/bansalbhunesh/parth/actions/runs/29458213865>.

| Metric | Value |
|---|---|
| Performance runs | 75, 97, 97, 97, 99 (**median 97**) |
| Median LCP | 2,535 ms |
| Median TBT | 74 ms |

The median mobile performance clears the 95 lab target on a clean Linux runner. The
single 75 is a cold-start outlier on the first run; four of five runs scored ≥ 97.
Total Blocking Time collapsed from the Windows 654 ms to 74 ms, which confirms the
earlier median-79 was CPU starvation on the memory-constrained Windows host, not a
bundle-budget problem. This is a lab measurement; production INP p75 (field data)
remains a separate required artifact.
